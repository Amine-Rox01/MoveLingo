# MoveLingo classroom feasibility protocol

Status: protocol/template; no results have been collected by the software author.

## Before a pilot

1. Obtain the school/institution's required approval and appropriate participant/guardian arrangements. Ask an English educator and a qualified PE educator to review the pack, usable space, stop signal and adaptations. Keep names and sensitive details outside this app.
2. Record lesson/version, class size, age band, English level, actual usable space, equipment, group rotation and the agreed movement alternatives.
3. Define one observable English criterion and one physical criterion. Use the same criteria and anonymous learner IDs at each observation point. Do not grade English through athletic ability.
4. Prepare two comparable short tasks, A and B, with the same demands and different surface details. Use one for baseline and one after the lesson. Record differences and support given; repeating an identical task may measure memory of its answer.

## Observation procedure

- Baseline: collect a short language response and observe the agreed movement criterion when appropriate.
- Teach the task using the private role cards and demonstration. Do not reveal the private solution to learners before the task.
- After task: collect a comparable individual language sample and physical observation. Use 1 = substantial support, 2 = some support, 3 = independent; blank = not observed. Add the actual evidence, not only a rating.
- If feasible, repeat a comparable check after an agreed interval; record that interval. Keep absence separate from low performance.
- Record meaningful participation opportunities, group rotation, teacher preparation time, instructions that failed and changes made.
- Invite brief voluntary learner and teacher comments. Keep permitted, anonymized work samples separately and note the basis for any classroom recording or image use.

## Analysis and reporting

Report the actual participant/observation counts and missing data. Compare only matched learners observed under matching criteria; describe changes in support, not a standardized proficiency score. Explain how adaptations or task difficulty changed. Include negative and ambiguous findings.

A small uncontrolled pilot can show feasibility and observed changes. It does not establish that MoveLingo caused learning gains. Seek research-method advice for a controlled comparison or publication. Do not invent improvement percentages, testimonials, approvals or trial photos.

## Suggested report fields

Context; question; participant/observation counts; instruments; activities; adaptations; data handling; findings; failures; limitations; next revision.
